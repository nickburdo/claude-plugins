# claude-plugins

A Claude Code plugin marketplace by nickburdo.

## Install

```text
/plugin marketplace add nickburdo/claude-plugins
/plugin install <plugin>@nickburdo-plugins
```

## Plugins

| Plugin | Description |
| --- | --- |
| [dev-workflow](plugins/dev-workflow) | Plan-first development workflow: start-task and finish-task skills, PR descriptions, a browser-checker agent and a hook that blocks edits on protected branches. |
